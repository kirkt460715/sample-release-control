# 试销批抽检交接

抽样号、产地工艺与分箱号各自独立。检验凭证覆盖随批抽样、后续补样、耗样及投诉复查。 数据全部为合成业务记录。文件使用 UTF-8 JSON，时间均为北京时间，货币如无单独说明均为人民币分。

## 查阅交接数据

使用 Python 3.11 标准库。在仓库根目录运行 `python3 inspect_delivery.py` 查看交接文件和行数，或在后面加文件名（含 `.json`）查看该文件的第一条记录。这个入口仅供查阅交接资料。

## 数据约定

- `lots.json` 生产批以及可分层工艺，qty 为含耗样件的原始件数。
- `cartons.json` 实际封箱身份、件数和可能来源；多候选来源表示混装不可拆定。耗样从原批未分箱的余额先扣，分箱记录与抽样账共用原批总量。
- `checks.json` stage 为计划中可作正式结论的检查轮次，指定件仅供追查。revision 为同一样品凭证更正，按评估时已入账的最新凭证判断有效性。已耗样由原凭证记录，后续结果状态更正不会返还实物。
- `policies.json` 渠道独立的缺陷比例上界、错误概率上限、至多正式查看次数及累计试销件数。发现有效关键缺陷即按所在生产批追查。
- `requests.json` 申请时次与可办箱号，实际领箱以签领为准，不拆销售箱。
- `fulfillment.json` 签领事实。actual_units 为空表示只签预约、还未出库。

## 检查资料

运行 `python3 -m unittest discover -s tests -v`。检查会读取当前交接文件，核对该业务所需的关键原始证据是否齐备。
